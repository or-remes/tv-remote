# שלט לממיר

אפליקציית אנדרואיד אישית ששולטת בממיר Android TV (למשל הממיר של פרטנר) דרך ה-Wi-Fi הביתי.

## התקנה על הטלפון

1. היכנס מהטלפון לעמוד **Releases** של הריפו והורד את הקובץ `tv-remote.apk` מהגרסה האחרונה.
2. פתח את הקובץ. אם אנדרואיד שואל, אשר התקנה מהדפדפן (או מהאפליקציה שממנה הורדת).
3. פתח את האפליקציה "שלט".

## שימוש בפעם הראשונה

1. ודא שהטלפון והממיר מחוברים לאותו ווי-פיי ושהממיר דולק.
2. באפליקציה: **חיפוש אוטומטי**, או הקלדה ידנית של כתובת ה-IP של הממיר (בהגדרות הרשת של הממיר).
3. לחץ **התחבר**. על מסך הטלוויזיה יופיע קוד בן 6 תווים. הקלד אותו באפליקציה.
4. מאותו רגע האפליקציה זוכרת את הצימוד.

## הערות

- הצימוד נשמר בטלפון. אם הוא נמחק (למשל אחרי איפוס הממיר), לחץ **צימוד מחדש**.
- שמירה על כתובת IP קבועה לממיר (בהגדרות הנתב) חוסכת חיפוש בכל פעם.
- הקוד לא שולח שום דבר החוצה מהרשת הביתית.
